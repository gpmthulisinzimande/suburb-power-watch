Project Objective

Design a brand new mobile app that solves a real-world problem. Learn design thinking, creativity, entrepreneurship, and presentation skills.

How It Works

Brainstorm an app idea, research the problem and build an app using tools such as Lovable, Bolt.new, v0 by Vercel, ChatGPT, GitHub Copilot.

 

Project Steps:

Identify a problem people face in your community.

Design an app that solves the problem.

Prepare a 2-minute investor pitch.

Pitch Requirements

What problem does the app solve?

Who is the target user?

What are the key features?

How will it help people or generate value?

Why is it better than existing solutions?
